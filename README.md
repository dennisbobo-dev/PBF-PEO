# PBF Global Workforce Advantage

Password-protected Railway preview for the Industrious PEO campaign. This sample is informational only: submissions are disabled and no customer data is stored. Configure `PREVIEW_USER` and `PREVIEW_PASSWORD` in Railway before assigning a domain. Start command: `python main.py`; binds to `$PORT`.

The public GitHub repository contains no credentials or prospect data. Restrict GitHub repository visibility separately if desired.
